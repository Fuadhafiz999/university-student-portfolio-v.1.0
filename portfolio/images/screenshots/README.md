## How to Take Screenshots

### Desktop Screenshots
1. Open the portfolio in Chrome (full screen)
2. Use Chrome DevTools (F12) to set viewport to 1920x1080
3. Take full-page screenshots or section-specific shots
4. Save as PNG with the filenames above

### Mobile Screenshots
1. Open Chrome DevTools (F12)
2. Toggle device toolbar (Ctrl+Shift+M)
3. Select iPhone 12/13/14 (375 x 812)
4. Take screenshots of key sections

### Creating GIFs
Use one of these tools:
- **[LICEcap](https://www.cockos.com/licecap/)** — Simple, lightweight
- **[ScreenToGif](https://www.screentogif.com/)** — Windows, feature-rich
- **[Kap](https://getkap.co/)** — macOS, beautiful UI
- **[CloudApp](https://www.getcloudapp.com/)** — Online, no install

### GIF Recording Tips
1. Set frame rate to 10-15 FPS (smaller file size)
2. Record for 5-10 seconds max
3. Focus on one section at a time
4. Show scroll animations in action
5. Export as GIF (not video)

## File Naming Convention
- Use lowercase with hyphens: `hero-section.png`
- No spaces or special characters
- Consistent format (PNG for screenshots, GIF for animations)

## Image Optimization
Before uploading:
1. Compress PNGs with [TinyPNG](https://tinypng.com/)
2. Optimize GIFs with [ezgif.com](https://ezgif.com/optimize)
3. Keep file sizes under 500KB for fast loading
4. Use descriptive filenames for accessibility

## Quick Commands

### Take Full Page Screenshot (Chrome DevTools)
1. Open DevTools (F12)
2. Press `Ctrl+Shift+P` (Windows) or `Cmd+Shift+P` (Mac)
3. Type "screenshot"
4. Select "Capture full size screenshot"

### Take Element Screenshot
1. Right-click on element
2. Select "Inspect"
3. Right-click on highlighted HTML
4. Select "Capture screenshot"
