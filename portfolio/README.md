## About the Project

This portfolio is a **single-page application (SPA) style website** designed to serve as a comprehensive digital resume and personal brand showcase. It goes beyond a traditional CV by combining stunning visual design, smooth animations, and interactive elements to create a memorable first impression.

The portfolio is built entirely with **vanilla HTML, CSS, and JavaScript** — no frameworks, no build tools, no complexity. This means it's:

- ⚡ **Lightning fast** — No framework overhead
- 📱 **Fully responsive** — Works on all devices
- 🔧 **Easy to customize** — Simple, well-organized code
- 🌐 **SEO friendly** — Clean semantic HTML structure
- ♿ **Accessible** — Built with accessibility best practices

## Why This Portfolio Works

### 🎯 **First Impression Matters**
The portfolio opens with an **animated hero section** featuring:
- A dynamic typing effect that cycles through your roles
- Smooth entrance animations using AOS (Animate on Scroll)
- A parallax video background that adds depth
- Floating profile image with gradient border
- Quick-access social media links

**Why it works:** Recruiters spend an average of **6-7 seconds** on initial resume screening. This hero section immediately communicates professionalism and technical competence.

### 📱 **Mobile-First Responsive Design**
Every section is optimized for:
- Desktop (1200px+)
- Tablet (768px - 1199px)
- Mobile (below 768px)

**Why it works:** Over **60% of web traffic** comes from mobile devices. A responsive portfolio ensures you never miss an opportunity, regardless of how someone discovers you.

### ✨ **Smooth Animations & Micro-Interactions**
The portfolio includes:
- Scroll-triggered reveal animations
- 3D card tilt effects on hover
- Magnetic button interactions
- Parallax scrolling effects
- Counter animations for statistics
- Custom cursor (desktop only)

**Why it works:** Animations guide the user's attention, create visual hierarchy, and demonstrate your attention to detail — a critical skill for any technical role.

### 🏗️ **Information Architecture**
The portfolio follows a logical flow:
1. **Hero** → Who you are
2. **Stats** → Quantified achievements
3. **Skills** → What you can do
4. **Projects** → What you've built
5. **Testimonial** → Social proof
6. **CTA** → How to reach you

**Why it works:** This structure mirrors the way recruiters evaluate candidates — from quick impression to detailed assessment.

### 🎨 **Professional Design System**
Built with a cohesive design system including:
- Consistent color palette (Blue primary with cyan accent)
- Typography hierarchy (Inter + Space Grotesk + JetBrains Mono)
- Reusable component library (cards, buttons, badges)
- CSS custom properties for easy theming

**Why it works:** Consistency signals professionalism and attention to detail.

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- A code editor (VS Code recommended)
- Basic knowledge of HTML, CSS, and JavaScript

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/portfolio.git
   cd portfolio
   ```

2. **Open in browser**
   ```bash
   # Simply open index.html in your browser
   open index.html        # macOS
   xdg-open index.html    # Linux
   start index.html       # Windows
   ```

3. **Or use a local server** (recommended)
   ```bash
   # Using Python
   python -m http.server 8000

   # Using Node.js
   npx serve

   # Using VS Code
   # Install "Live Server" extension and click "Go Live"
   ```

4. **View in browser**
   ```
   http://localhost:8000
   ```

## Customization

### 🎨 Change Colors

Edit `css/base.css` to update the color palette:

```css
:root {
  --primary: #2563eb;        /* Primary blue */
  --primary-dark: #1d4ed8;   /* Darker shade */
  --primary-light: #60a5fa;  /* Lighter shade */
  --accent: #06b6d4;         /* Cyan accent */
  /* Add your custom colors */
}
```

### ✏️ Update Content

Replace placeholder content with your own information:

1. **Personal Info** — Edit `index.html` hero section
2. **About Me** — Update `pages/about.html`
3. **Projects** — Add your projects to `pages/portfolio.html`
4. **Experience** — Update `pages/training.html`
5. **Contact** — Modify `pages/contact.html`

### 🖼️ Replace Images

Replace images in the `images/` folder or update URLs in the HTML files. Recommended image sizes:

| Image Type | Recommended Size |
|------------|------------------|
| Profile Photo | 600 x 600 px |
| Project Thumbnails | 800 x 600 px |
| Background Images | 1920 x 1080 px |

### 🔗 Update Social Links

Find and replace social media URLs across all HTML files:

```html
<!-- Replace these with your actual profiles -->
<a href="https://github.com/yourusername">GitHub</a>
<a href="https://linkedin.com/in/yourusername">LinkedIn</a>
<a href="https://twitter.com/yourusername">X (Twitter)</a>
<a href="https://instagram.com/yourusername">Instagram</a>
```

### 📄 Add/Remove Sections

Each section is self-contained in its own HTML file. To add a new section:

1. Create a new HTML file in `pages/`
2. Copy the navigation and footer from any existing page
3. Add your content
4. Add a navigation link in all pages

## Performance & Optimization

### ⚡ Performance Features

- **Lazy Loading** — Images load only when visible
- **Passive Event Listeners** — Non-blocking scroll handlers
- **CSS Containment** — Isolates rendering
- **Minimal Dependencies** — Only essential libraries
- **Optimized Images** — WebP format where supported

### 📊 Lighthouse Scores (Target)

| Metric | Score |
|--------|-------|
| Performance | 95+ |
| Accessibility | 90+ |

### 🛠️ Optimization Tips

1. **Compress images** — Use tools like Squoosh or TinyPNG
2. **Enable caching** — Add cache headers if using a server
3. **Minify assets** — Use CSS/JS minifiers for production
4. **Use CDN** — Serve static assets from a CDN
