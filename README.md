## 🎨 Design System

The portfolio uses a comprehensive **CSS Custom Properties** system for easy theming:

### 🎯 Brand Palette
```css
--primary: #2563eb;      /* 🔵 Primary Blue */
--primary-dark: #1d4ed8; /* 🔵 Dark Blue */
--primary-light: #60a5fa;/* 🔵 Light Blue */
--secondary: #0f172a;    /* ⚫ Dark Navy */
--accent: #06b6d4;       /* 🔷 Cyan Accent */
```

### 📝 Typography
| Font | Usage | Weight |
|:-----|:------|:-------|
| **Inter** | Body text, paragraphs | 300-700 |
| **Space Grotesk** | Headings, titles | 400-700 |
| **JetBrains Mono** | Code snippets, labels | 400-500 |

### 🌈 Gradients
```css
--gradient-primary: linear-gradient(135deg, #2563eb, #06b6d4);
--gradient-hero: linear-gradient(135deg, #0f172a 0%, #1e3a5f 50%, #0f172a 100%);
```

## 🏁 Getting Started

### Prerequisites
- 🌐 Any modern web browser (Chrome, Firefox, Safari, Edge)
- 📁 Text editor (VS Code recommended)

### Installation

1️⃣ **Clone the repository**
```bash
git clone https://github.com/Fuadhafiz999/university-student-portfolio-v.1.0.git
cd university-student-portfolio-v.1.0
```

2️⃣ **Open in browser**
```bash
# Simply open index.html in your browser
open index.html        # macOS
start index.html       # Windows
xdg-open index.html    # Linux
```

3️⃣ **Or use Live Server** (recommended for VS Code)
```bash
# Install Live Server extension, then right-click index.html → "Open with Live Server"
```

> **💡 No build tools, npm install, or server configuration required!** All libraries are loaded via CDN.

## 🎨 Customization

### Change Brand Colors
Edit `css/base.css` to update the color palette:
```css
:root {
  --primary: #your-color;
  --accent: #your-color;
}
```

### Update Content
- **Personal Info**: Edit `index.html` and `pages/about.html`
- **Projects**: Edit `pages/portfolio.html`
- **Contact**: Edit `pages/contact.html`
- **CV**: Replace `pdf/Ahshan Hafiz Fuad - CV.pdf`
